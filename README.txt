================================================================
  部落冲突(国际服) 部落战成员战斗情况查看器 使用说明
================================================================

一、软件功能
------------------------------------------------------------
1. 查询当前部落战: 查看战斗日/准备日/已结束的部落战中
   每一位成员的战斗情况,包括:
   - 进攻次数、总星数、总摧毁率、场均星、最佳进攻
   - 被攻星数、被摧毁率、未进攻次数
   - 双击某一行,可查看该成员每一次进攻与防守的明细
   (对手是谁、几星、摧毁率、用时)

2. 部落联赛 CWL: 查看联赛每一轮(第1~7轮)的成员数据,
   以及"汇总(全部轮次)"的全赛季统计数据。

3. 战争日志: 查看最近30场部落战的胜负汇总。
   (注: 官方API不提供常规部落战的历史成员明细)

4. 导出CSV: 把当前表格保存为CSV文件,Excel可直接打开。

   启动时若已保存过令牌和标签,程序会自动查询一次当前部落战;
   点"刷新"可随时重新获取最新战况。

   当前部落战视图每30秒自动刷新一次;
   点"暂停刷新"可冻结当前数据(比如想截图或对比时不被打断),
   按钮会变成"继续刷新",点它恢复自动刷新。

   行颜色说明:
   绿色 = 打出过3星; 橙色 = 最高1~2星; 红色 = 只打出0星;
   灰色 = 还未进攻。

二、使用前提(重要): 获取 API 令牌
------------------------------------------------------------
本软件基于 Clash of Clans 官方 API,需要一枚免费令牌:

1. 用浏览器打开 https://developer.clashofclans.com
2. 点击右上角登录(谷歌账号、Supercell ID 等均可)
3. 登录后点 "Create Key":
   - 名称(Name): 随意填写
   - 描述(Description): 随意填写
   - IP 地址(IP Address): 填写你当前电脑的【公网IP】
     (点"我的IP"可自动填入; 换网络后 IP 变了必须重建令牌)
   - 勾选 Clash of Clans
   - 点 Create Key,复制生成的令牌
4. 把令牌粘贴到软件顶部的"API令牌"框;
   部落标签填入"部落标签"框,例如 #2LJQ2YVY
   (带 # 或不带 # 都可以,程序自动识别)

三、常见问题
------------------------------------------------------------
1. 提示"令牌无效或来源IP未授权(403)":
   - 令牌与IP绑定,换网络(如切换WiFi/热点/挂代理)后需
     到 developer.clashofclans.com 重新创建令牌。
2. 提示"当前没有进行中的部落战":
   - 部落未开战,或战争已结束且官方API已不再提供数据。
3. 提示"请求过于频繁(429)": 稍等片刻再点"刷新"。
4. 提示"当前不在部落对战联赛期":
   - 联赛每月1日开战; 联赛结束后官方API不提供往届数据,
     请在联赛期间(每月1~8日)查看。

四、关于数据
------------------------------------------------------------
所有数据均来自 Supercell 官方 Clash of Clans API,
程序不收集、不上传任何个人信息; 令牌仅保存在本机
(%APPDATA%\CoCWarViewer\config.json)。
